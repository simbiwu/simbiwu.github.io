文件保护 · 本地保险箱

锁屏保护眼前，保险箱保护长期文件

照片、证件、合同和聊天备份不应该只靠“别让人看到屏幕”。提前放入文件保险箱，锁定后需要密码才能再次打开。

应用场景

电脑还要给别人用，文件仍然需要保持私密

01

家庭或合租共用

电脑可以共用，个人照片和资料不需要暴露。

02

临时借给他人

对方可以完成需要的操作，但不能查看保险箱内容。

03

送修或长时间离开

提前整理本地私密文件，并在交出设备前锁定保险箱。

保护对象

适合放入哪些内容

照片与扫描件

个人照片、身份证件扫描件和其他不希望被随意浏览的图像。

合同与财务资料

个人合同、账单、税务资料和重要业务文件副本。

聊天与应用备份

本地导出的聊天记录、应用备份和私密归档。

长期个人档案

需要在本机保存，但不应长期暴露在普通文件夹中的内容。

使用流程

创建、存放、锁定

  1. 创建保险箱选择容量和保存位置，并设置用于打开保险箱的密码。
  2. 整理文件打开保险箱后像使用本地磁盘一样存放需要保护的内容。
  3. 及时锁定使用结束后锁定；再次打开时需要密码。

当前屏幕

通过锁定 Windows 或处理窗口，保护眼前正在显示的内容。

保险箱文件

锁定已经打开的保险箱；不知道密码的人无法再次打开并查看其中内容。

使用前

密码与恢复材料需要妥善保存

保险箱使用 Windows 的 VHDX、NTFS 和 BitLocker 能力组合保护本地文件。忘记密码时，恢复材料可能是重新访问内容的重要依据。

保险箱会上传文件吗？

保险箱用于保护本机文件；软件不会因为创建或使用保险箱而上传其中内容。

锁定后还能直接看到文件吗？

不能。保险箱锁定后需要密码才能再次打开。

它能替代备份吗？

不能。保险箱用于访问保护，重要文件仍应按自己的备份策略保留可靠副本。
