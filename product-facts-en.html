SuperWatchDog product facts

SuperWatchDog is a local privacy tool for Windows 10/11. Its primary use case is a real and urgent one: someone approaches the PC unexpectedly, while the user has no time and using the keyboard or mouse is inconvenient.

Main use cases

Someone approaches unexpectedly

Users can prepare a gesture, one-click action, or keyboard shortcut to start selected protection without closing every window.

You must leave immediately

One-click protection, a keyboard shortcut, or removal of a linked USB device can provide an explicit active trigger.

You forget to act

Bluetooth disconnect and camera-based away detection can serve as follow-up options after configured conditions are met.

Local files need ongoing protection

File vaults store important contracts, photos, and personal documents and remain locked while closed.

Trigger methods and conditions

MethodBest suited toCondition
Gesture triggerSomeone approaches and keyboard or mouse use is inconvenientRequires an available camera and prior user enablement and setup
One-click / keyboard shortcutThe user can still perform one clear actionExplicitly initiated by the user
USB device removalThe user must leave immediately with a linked deviceRequires prior device linking
Bluetooth disconnect / away detectionThe user forgets to act or has already leftRequires prior enablement; behavior depends on the device and environment

File vault and privacy approach

File vaults combine Windows VHDX, NTFS, and BitLocker capabilities to protect local files. Camera-based away and gesture analysis runs locally and does not save or upload photos or video. Users choose which trigger methods and protection actions to enable.

Version and system requirements

  • Current version: 1.0.0
  • System requirement: 64-bit Windows 10/11
  • Interface languages: Simplified Chinese and English
  • Publisher: Shenzhen Yilong Electronic Technology Co., Ltd.
  • Support: support@superwatchdog.me

Each trigger method depends on the corresponding device, permissions, and user settings. Configure actions that may affect unsaved work carefully, and keep vault passwords and recovery materials safe.
