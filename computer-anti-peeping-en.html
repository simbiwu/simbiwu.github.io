PC privacy takes more than a screen filter

SuperWatchDog is a local privacy protection tool for Windows. User-configured automatic triggers cover moments when someone approaches unexpectedly, normal PC interaction is inconvenient, or the user has already left without protecting the session. It also provides encrypted local file vaults.

Four exposure layers

Start with what another person could see or use

“Privacy” is an outcome, not the name of a single button. Each exposure layer needs a different control.

01

Viewing angle

Seat position, screen direction, and privacy filters reduce what can be read from the side.

02

Visible content

Chats, photos, notifications, or shared-screen content may need immediate window hiding or screen locking.

03

Unlocked session

After you leave, hiding a window does not stop someone from continuing to use the current Windows session.

04

Local files

A hidden screen does not mean photos, contracts, and identity scans stored on disk are encrypted.

Trigger choice

The same person needs different triggers at different moments

Still at the PC

Use a shortcut or one-click action when reachable, or an enabled gesture when keyboard use is inconvenient.

Leaving immediately

Removing a prepared USB device can provide an explicit trigger when it already matches your routine.

Already away

Bluetooth disconnect or away detection can supplement manual methods after environmental testing.

Unsure what to run

Start with reversible, lower-impact actions, then decide whether the Windows session should be locked.

Use methods together

Software helps cover the moments when normal interaction is too late

Current screen and windows

SuperWatchDog runs user-selected triggers and actions for the current session. It does not judge screen content or promise to detect every approach automatically.

Private files stored locally

Encrypted local file vaults suit files that need an explicit open-and-lock boundary. Hiding folders, hiding windows, and encryption are different layers.

Is a privacy filter enough?

It can reduce readability from the side, but cannot prevent front viewing, notifications, or continued use after you leave.

Should I hide windows or lock Windows?

Hide windows for brief cover while you remain present. Lock Windows whenever another person may continue using the PC.

Can automatic triggers misfire?

Device and camera signals can be affected by the environment. Enable only methods that fit your routine and test them before relying on them.
