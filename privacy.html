隐私说明

更新日期：2026 年 8 月 3 日

超级看门狗和超级恢复是在 Windows 电脑上运行的本地工具。本说明介绍官网、安装程序和 Windows 客户端会如何处理与你有关的数据。

适用范围

本说明适用于超级看门狗、超级恢复共用的官网，以及两款产品各自的安装程序和 Windows 客户端。如相关服务或数据处理方式发生变化，我们会同步更新本说明。

我们不收集的内容

  • 不上传你的文件、文件列表、恢复结果、预览内容、保险箱内容、密码或恢复密钥。
  • 不保存 BitLocker 密码明文，也不会替你保管恢复材料。
  • 不上传摄像头画面、系统截图、窗口内容或本地路径列表。
  • 不通过官网放置第三方统计脚本、广告脚本或远程字体。

本地处理

离机保护、设备状态和保险箱操作在你的 Windows 电脑上处理。基础保护功能不依赖远程账户或云端服务。文件保险箱、可信设备和保护方式由你在本机配置和管理。

超级恢复在本机读取你选择的磁盘或镜像，并把尝试恢复的内容保存在你选择的目标位置。扫描得到的文件名、路径、扇区数据、文件内容和预览内容不会发送到官网或授权服务。软件只会在你明确确认后把恢复结果写入磁盘。

本地日志与诊断

软件可能在本机记录必要的运行状态、错误信息和诊断日志。程序异常退出时，还可能在本机保存错误代码、软件版本、脱敏日志和受限数量的小型崩溃转储。

诊断报告仅在你主动确认后发送或导出。小型崩溃转储默认不加入报告，需要你单独勾选；转储可能包含故障线程附近的少量内存信息。报告不收集保险箱内容、文件列表、密码、恢复密钥、摄像头画面、屏幕截图或窗口内容。

网站访问统计

官网使用自有的第一方匿名统计，用于了解页面浏览量、原始访客、浏览器确认活动、候选访客、热门页面、首次访问来源、推广活动、落地页，以及浏览器、设备类型、界面语言和国家、省份级地域分布。网站会设置一个不包含身份、账号、设备或 IP 信息的第一方随机标识，服务器只保存该标识的哈希；浏览器和设备类型由访问时的浏览器信息归类，访问来源仅保存为直接访问、搜索引擎、GitHub 或已支持的内容平台等类别，推广活动仅保存网址中受控的 utm_source 和 utm_campaign 标记，不保存完整来源网址或其它查询参数。浏览器可在当前会话内临时保留这两个受控标记，用于同一次访问中的站内页面和下载入口归因。页面在前台可见至少 10 秒，或者发生点击、按键、触摸、滚动后，网站会为同一匿名标识提交一次浏览器确认活动；确认只保存公开页面路径、接收时间和标识哈希，不保存交互类型、交互内容、坐标或按键。浏览器确认活动，或同一北京时间自然日产生至少两次页面浏览，只用于派生候选访客，并不等同于已确认真人。运营分类不会在同一数据基线内删除或改写原始访客和页面浏览；匿名运营数据可按保留或系统维护策略清理，不影响诊断报告。请求 IP 仅在服务器本地转换为国家和省份级地域后立即丢弃，原始 IP、城市和精确位置不写入运营数据库。已识别的爬虫不计入网站访客或页面浏览。统计失败不会影响网站使用，官网不使用第三方统计、广告或追踪服务。

下载与更新

官网可能提供安装程序下载地址。下载安装包时，你的浏览器或下载服务可能与对应下载服务器通信。下载入口沿用或设置同类第一方随机标识，用于按浏览器、北京时间自然日、版本和渠道区分下载发起、完整传输与重复请求，并将首次访问来源、推广活动和落地页关联到下载转化；服务器只保存标识的哈希，不据此识别个人。安装包完整传输后才计入下载完成，中断或取消的传输不计入完成；英文页面使用 GitHub Release 外部镜像，官网可以记录下载发起，但无法确认站外传输是否完成，因此不计入下载完成。入口请求次数仅用于流量和故障诊断。已识别的搜索引擎爬虫不计入独立下载发起或下载完成。语言选择仅保存在当前浏览器本地。超级看门狗官网不嵌入第三方统计、广告或追踪脚本。

限时专业版联网说明

免费版和永久授权无需联网确认授权期限。使用限时专业版时，软件会定期通过加密连接确认授权是否仍在有效期内。该请求不发送设备身份、授权编号、保险箱信息、设备列表或使用统计。

匿名使用统计

软件可能发送随机安装编号、软件版本、发布渠道、Windows 版本与构建号、系统架构、界面语言和启动记录，用于统计首次启动、启动活跃、留存及版本和系统分布。下载安装程序和提交启动记录时，服务器会在本地将请求 IP 转换为国家和省份级地域，用于汇总下载与首次启动地域；原始 IP、城市和精确位置不写入运营数据库。首次启动表示服务器第一次观察到该随机编号的启动记录，不等同于已确认安装成功。随机安装编号不来自硬件或 Windows 账号，统计内容也不包含保险箱信息、设备列表、文件路径或摄像头画面。数据仅通过加密连接发送，发送失败不会影响软件功能。

用户责任

请妥善保管保险箱文件、BitLocker 密码和恢复材料。如果忘记密码并丢失恢复材料，保险箱内容可能无法恢复。超级看门狗不会保存你的 BitLocker 密码明文，也无法替你解密保险箱。
