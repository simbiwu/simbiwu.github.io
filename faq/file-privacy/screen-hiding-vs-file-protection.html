私密文件保护

隐藏屏幕内容，为什么不能代替私密文件保护？

简短回答

隐藏窗口只改变当下看到的内容，文件仍可能存在于磁盘和最近记录中；私密文件需要单独放入受 BitLocker 保护的保险箱，并在不用时锁定。

屏幕隐私与文件隐私是两层

窗口隐藏适合处理突然有人看向屏幕的瞬间，Windows 锁屏用于阻止继续操作当前会话。它们不会自动把已经存放在普通文件夹中的文件迁移或加密。

保险箱更适合照片、证件扫描件和工作资料等长期敏感内容。打开时它会像磁盘一样供应用使用；离开前保存并关闭文件，再锁定保险箱。

  • 屏幕层：隐藏或锁屏
  • 存储层：加密保险箱
  • 日常层：减少普通目录中的副本和导出文件
