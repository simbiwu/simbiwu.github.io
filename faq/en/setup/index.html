Setup and device requirements

Check Windows, BitLocker, and camera privacy requirements before choosing features you can actually use.

3 questions · Last reviewed 2026-08-01

Which Windows versions are supported, and does Home edition work?

Version 1.0.0 targets 64-bit Windows 10 and 11, with Pro, Enterprise, or Education recommended. Home can use basic triggers and Windows lock, but normally cannot use vault creation and protection that depend on system BitLocker.

Read the full answer →

What can I do when BitLocker is unavailable?

You can still use shortcut, device, or camera triggers for basic window and Windows-lock protection, but you cannot create or rely on a BitLocker vault for sensitive files.

Read the full answer →

Does camera detection save or upload images?

No. Camera detection is processed locally, does not identify faces, and does not save, record, or upload images. Camera features are disabled by default and operate only after the user enables them.
