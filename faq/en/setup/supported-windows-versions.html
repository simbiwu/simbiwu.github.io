Setup and device requirements

Which Windows versions are supported, and does Home edition work?

Short answer

Version 1.0.0 targets 64-bit Windows 10 and 11, with Pro, Enterprise, or Education recommended. Home can use basic triggers and Windows lock, but normally cannot use vault creation and protection that depend on system BitLocker.

Separate basic protection from the vault

Quick triggers, window handling, and Windows lock are basic protection. The encrypted vault depends on BitLocker supplied by Windows, so availability varies with the Windows edition and device configuration.

Windows 7, 8, and 8.1 are not supported. Check the Windows edition and architecture before installing or buying; if the vault is your goal, also confirm that BitLocker is available.

  • Supported: 64-bit Windows 10 and 11
  • Recommended: Pro, Enterprise, or Education
  • Home: primarily basic triggers and Windows lock
