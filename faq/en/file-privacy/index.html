Private file protection

Go beyond covering the screen to file protection, lending or repairing a PC, and vault access boundaries.

4 questions · Last reviewed 2026-07-31

Why does hiding the screen not replace private file protection?

Hiding windows changes only what is visible now; files may still remain on storage or in recent history. Sensitive files need their own BitLocker-protected vault, locked when not in use.

Read the full answer →

How should I store photos, identity scans, and contracts?

Keep long-term sensitive originals together in an encrypted vault and retain only necessary copies in normal folders. Close files and lock the vault after use, and store recovery material separately.

Read the full answer →

What should I check before lending or repairing my PC?

Save work and lock the vault, check that sensitive files are not scattered across Desktop, Downloads, or sync folders, and sign out of accounts that need not be exposed. Prepare repairs using data minimization.

Read the full answer →

Why is a password still required when a trusted device is present?

A trusted device is only a condition for entering the open flow; it is not the vault password. You still enter the BitLocker password so possession of the device alone does not reveal files.
