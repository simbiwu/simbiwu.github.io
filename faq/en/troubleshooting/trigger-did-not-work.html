Troubleshooting and safety

What should I check first when a trigger does not protect the PC?

Short answer

Confirm that the trigger is enabled and its device or camera is available, then use manual Protect Now to test the action itself. Review the in-app trigger history and understandable error message afterward.

Separate the trigger from the action

If manual protection works, investigate shortcut conflicts, device recognition, Bluetooth connectivity, or camera conditions. If the manual action also fails, follow the page guidance for Windows permissions, sign-in state, or files still in use.

Do not immediately switch to a forceful restart while troubleshooting. Verify the basic flow with Windows lock or window hiding, and note the time, selected trigger, and displayed error code for support.

  • Confirm the feature switch and target device
  • Test manual protection first
  • Review trigger history and error code
  • Change one condition at a time
