Emergency screen privacy

What if I have no time to organize private windows before screen sharing?

Short answer

When possible, share one application and disable notifications. If an ad-hoc presentation has already started, use a configured action to hide windows that should not be shown. This is a fallback, not a replacement for a pre-meeting check.

Limit the shared area before relying on an emergency action

Share only the presentation application rather than the full desktop when the meeting tool allows it. Check the desktop, taskbar, browser tabs, and notification previews, then preview the output before others join.

For an unexpected meeting, hide previously selected private windows and verify the shared view. The software cannot infer which window is appropriate to show; users choose the target windows and protection actions.

  • Prefer sharing one application
  • Disable message and email previews
  • Check the actual shared output
