Emergency screen privacy

In an urgent moment, should I lock Windows or only hide windows?

Short answer

Hide windows for brief visual cover. Lock Windows whenever someone might continue using the PC. Neither action replaces encryption for sensitive files.

The actions solve different problems

Hiding windows interrupts work less, but the PC remains usable and another person may find the windows again. Windows lock requires signing in again and is better when you leave or someone may touch the device.

If your concern is opening or copying files from storage, keep those files in a protected vault and confirm that the vault is locked before leaving.

  • Hide windows: fast and low-impact, but not access control
  • Lock Windows: prevents direct use of the current session
  • Lock the vault: protects access to files inside it
