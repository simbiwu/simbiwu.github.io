安装与设备条件

确认 Windows 版本、BitLocker 条件和摄像头隐私，再选择能够实际使用的功能。

支持哪些 Windows 版本？家庭版能用吗？

1.0.0 面向 Windows 10/11 64 位系统，推荐专业版、企业版或教育版。家庭版可使用基础触发与锁屏能力，但通常无法使用依赖系统 BitLocker 的保险箱创建与保护。

系统没有可用的 BitLocker，还能做什么？

仍可使用快捷键、设备或摄像头触发的基础窗口与锁屏保护，但不能创建或依赖 BitLocker 保险箱来保护私密文件。

查看完整回答 →

摄像头检测会保存或上传画面吗？

不会。摄像头检测在本机处理，不做人脸识别，不保存、录制或上传画面；相关功能默认关闭，只有用户主动开启后才使用。
