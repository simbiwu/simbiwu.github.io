安装与设备条件

支持哪些 Windows 版本？家庭版能用吗？

简短回答

1.0.0 面向 Windows 10/11 64 位系统，推荐专业版、企业版或教育版。家庭版可使用基础触发与锁屏能力，但通常无法使用依赖系统 BitLocker 的保险箱创建与保护。

先区分基础保护与保险箱

快捷触发、窗口处理和 Windows 锁屏属于基础保护。加密保险箱依赖系统提供的 BitLocker 能力，因此实际可用性取决于 Windows 版本和设备配置。

Windows 7、8 和 8.1 不在支持范围内。安装或购买前先查看系统版本与架构；如果目标是使用保险箱，还应确认系统能够使用 BitLocker。

  • 支持：Windows 10/11 64 位
  • 推荐：专业版、企业版、教育版
  • 家庭版：以基础触发和锁屏能力为主
